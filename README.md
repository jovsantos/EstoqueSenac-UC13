## 🚀 Como executar o projeto

1. Clone o repositório:

   ```bash
   git clone https://github.com/jovsantos/EstoqueSenac-UC13.git
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd EstoqueSenac-UC13
   ```

3. Instale as dependências:

   ```bash
   npm install
   ```

4. Inicie o Expo:

   ```bash
   npx expo start
   ```
